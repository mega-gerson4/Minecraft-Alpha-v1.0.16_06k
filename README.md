# Minecraft Alpha v1.0.16_06k

Olá, comunidade!

Encontrei uma versão esquecida do Minecraft Alpha entre arquivos antigos relacionados ao Minecraft Launcher.

Pelo que pude analisar, essa build parece ter sido utilizada somente durante testes internos e nunca chegou a ser disponibilizada publicamente.

Consegui recuperar os arquivos e preparar um instalador para que outras pessoas também possam testar a versão.

## Informações da build

- **Nome:** Minecraft Alpha v1.0.16_06k
- **Data registrada:** 6 de agosto de 2010
- **Estado:** Recuperada e jogável
- **Instalação:** Minecraft Launcher
- **Plataforma:** Minecraft Java Edition

## Download

O instalador está disponível na seção **Releases** deste repositório.

Feche completamente o Minecraft e o Minecraft Launcher antes de iniciar a instalação.
